## Problem and motivation

A single chest X-ray can show several findings at once, so the task is multi-label: each image can carry zero, one or many pathologies. In a medical setting a prediction is also not enough, a clinician needs to see where the model is looking. This project compares three architectures and adds explainability to every prediction.

## Technical approach

- **Backbones.** DenseNet121, ResNet50 and EfficientNet-B4, trained for multi-label output.
- **Explainability.** Grad-CAM heatmaps show which image regions drive each prediction. SHAP gives a complementary, attribution-based view.
- **Environment.** Training and experiments run on Kaggle and Google Colab.
