## Overview

Tunisia CoRide is a cross-platform mobile carpooling application designed to simplify shared transportation in Tunisia. It connects drivers offering available seats with passengers looking for convenient and affordable journeys.

The application provides an integrated experience for publishing rides, searching for available trips, managing reservations, and communicating between users.

## Key Features

- **User Authentication:** Registration, login, and password recovery using Firebase Authentication.
- **Profile Management:** Manage personal information, contact details, and profile pictures.
- **Ride Publishing:** Allow drivers to publish journeys with departure and destination locations, date, time, available seats, and price.
- **Ride Discovery:** Search for available journeys based on location, date, and trip preferences.
- **Booking Management:** Reserve seats and manage booking requests.
- **Notifications:** Firebase Cloud Messaging integration for important updates and booking notifications.
- **User Experience:** Onboarding, authentication, home, and search interfaces with continuous UI improvements.

## Technical Implementation

- Developed the mobile application using **Flutter and Dart**, targeting Android, iOS, web, and desktop platforms.
- Integrated **Firebase Authentication** for user identity management.
- Used **Cloud Firestore** for managing users, rides, and booking-related data.
- Incorporated Firebase services for storage and push notifications.
- Structured the application around reusable UI components and dedicated screens.
